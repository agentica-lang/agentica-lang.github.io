Agentica is Ruby with static types: Ruby-like syntax, every program checked before it runs, and values that never change in place. Tasks run in parallel on several cores, and it comes with HTTP, TLS and WebSockets, packages and C native modules, all in one binary, `agentica`.

## Install

Each release has an archive per system (Linux and macOS on x86-64 and arm64, Windows on x86-64), with `bin/agentica` inside. Unpack one and put its `bin` folder on your `PATH`. The [getting started guide](https://www.agentica-lang.com/agentica/getting-started/) lists the archives and runs your first program.
